# MusicMaster 🎵

MusicMaster is a modern and responsive online music store designed for music lovers. Users can explore and discover a variety of musical instruments and accessories through a clean and easy-to-use interface.

## 🌐 Live Website

https://music-masters-hazel.vercel.app/

## ✨ Features

- 🎸 Browse musical instruments
- 🎵 Explore music products and accessories
- 🔎 Search for products
- 🛒 Add products to cart
- 👤 User login and registration
- 📱 Fully responsive design
- 🎨 Modern and attractive user interface
- 🧭 Easy navigation
- 💻 Optimized for desktop and mobile devices

## 🛠️ Technologies Used

- React
- Next.js
- JavaScript
- HTML
- CSS
- Tailwind CSS
- Git & GitHub
- Vercel
